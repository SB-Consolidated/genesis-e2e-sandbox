# Coordinator Ticket Guide

**Version:** v0.9.7

## Responsibilities

- Draft tickets in `01_DRAFT` using `TICKET_TEMPLATE.md`.
- Use `TICKET-NNN` identifiers.
- Define dependencies and execution type.
- Decompose Phase 6 feedback through an approved revision spec before drafting refinement tickets.
- Submit tickets for Intent Overseer validation.
- After validation, write authorization and manage the merge lane.

## Do Not

- Use legacy examples such as category-prefixed ticket IDs.
- Treat chat confirmation as authorization.
- Draft refinement tickets directly from founder comments without a revision request and revision spec.
- Bypass the issue-guidance-escalation loop.
