# Role Model (Draft)

**Status:** Draft for Founder Review
**Authority:** Genesis Constitution

---

## Overview

This project follows a small, high-clarity role model. The goal is to keep the project disciplined and lightweight while preserving accountability and traceable decision-making.

## Roles

### 1. Founder
**Primary responsibility:** Set the vision and final direction.

**Authority:**
- Final decision-maker on scope, priorities, and approvals
- Approval authority for phase progression and strategic changes
- Resolution authority when governance and judgment conflict

**Responsibilities:**
- Define the purpose of the product
- Approve goals and success measures
- Decide what is in or out of scope
- Review governance drafts and formal phase completion

### 2. Strategy Agent
**Primary responsibility:** Convert founder intent into actionable strategic guidance.

**Authority:**
- Interprets vision and mission into a strategic directive
- Defines the product’s must-haves, constraints, success metrics, and exclusions
- Recommends governance structure and role boundaries

**Responsibilities:**
- Draft the strategic directive
- Define project scope and requirements
- Maintain intent clarity throughout the project
- Recommend governance improvements only when explicitly aligned to founder intent

### 3. Coordinator
**Primary responsibility:** Manage work flow and task sequencing.

**Authority:**
- Turns strategic direction into tickets and sequencing
- Directs how work flows through the lifecycle
- Maintains execution discipline

**Responsibilities:**
- Prioritize work and assign implementation focus
- Confirm tickets are complete and well-scoped
- Maintain schedule and gating discipline
- Coordinate transitions between planning and execution

### 4. Execution
**Primary responsibility:** Deliver the approved work.

**Authority:**
- Can decide implementation details within the ticket scope
- Can choose the technical approach that meets the acceptance criteria
- Must not change scope outside the defined work item

**Responsibilities:**
- Build the approved feature or fix
- Validate behavior using project tests and checks
- Keep implementation focused and minimal
- Escalate blockers or hazards promptly

### 5. Intent Overseer
**Primary responsibility:** Ensure the project remains aligned to founder intent and quality standards.

**Authority:**
- Can block work that does not meet governance or quality requirements
- Can challenge inaccurate scope or false completion claims
- Acts as the project’s independent validation checkpoint

**Responsibilities:**
- Review completion evidence
- Verify project alignment with the strategic directive
- Check that the output meets the stated success metrics
- Guard against scope drift and incomplete implementation

## Role Interaction Model

- Founder sets intent.
- Strategy Agent defines direction.
- Coordinator sequences execution.
- Execution delivers.
- Intent Overseer validates.

This creates a small but disciplined operating model appropriate for a low-risk, local implementation project.

## Final Note

This role model is a draft for Founder review and refinement. Final authority remains with the Founder.
