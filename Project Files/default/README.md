# Genesis Project Workspace

Project artifacts live here, separated from governance in `.genesis/`.

## Structure

- Genesis Execution/ - Governance execution artifacts
  - planning/ - Roadmap and planning summaries
  - reviews/ - Founder review reports and changelogs
  - revisions/requests, revisions/specs - Phase 6 revision intake and specs
  - tickets/01_DRAFT ... 05_COMPLETE - Ticket lifecycle folders
  - tickets/completion-contracts/ - Execution completion contracts
  - handoffs/ - Ticket and process handoffs
  - packets/ - Handoff packets
  - specs/UX Screens, UX Specs, Application Specs - Specifications
  - logs/ - Decision and execution logs
  - cache/ - Cached validation results and diagnostics
- docs/ (architecture, api, user-guides, deployment)
- src/
- tests/
- scripts/
- config/
- assets/
